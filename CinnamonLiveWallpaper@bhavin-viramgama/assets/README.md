# Assets Directory

Place your applet screenshots and demo video files in this folder for the `README.md` preview:

- `screenshot-menu.png` — Screenshot of the panel popup menu controls.
- `screenshot-settings.png` — Screenshot of the Applet Settings dialog window.
- `demo.mp4` or `demo.gif` — Short video/GIF demonstration of the live wallpaper in action.

*Tip: When uploading a video to GitHub issue or release/PR, GitHub will generate a asset URL like `https://github.com/user-attachments/assets/...` which you can paste directly into `README.md`!*
